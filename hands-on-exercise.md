# Hands-On Exercise: Write Your First Framework Prompt

Use this during the "Your Turn" section of the workshop (~12 minutes). Pick one real task you already do at least weekly — the more boring and routine, the better this works.

## The framework, as a worksheet

Fill in each line for **one real task**. Don't overthink it — a rough first pass is the point.

```
TASK
What do you want the AI to actually produce?
(e.g., "Draft a two-paragraph update for parents about next week's field trip.")

> ________________________________________________


CONTEXT
What background does it need that it can't guess?
(e.g., "The trip is Tuesday, meet at the front gate at 8am, bring a packed lunch,
permission slips are due Friday.")

> ________________________________________________
> ________________________________________________


FORMAT
What should the output look like?
(e.g., "Two short paragraphs, warm but brief tone, no bullet points.")

> ________________________________________________


EVALUATE
Before you use it, what would make this good enough?
(e.g., "Has the date, time, and permission-slip deadline. Doesn't sound robotic.")

> ________________________________________________


ITERATE
If it's not quite right the first time, what's the one thing you'd ask it to change?
(e.g., "Make the tone warmer" / "Shorten it by half" / "Add the lunch reminder.")

> ________________________________________________
```

## Two worked examples, for inspiration

**Example 1 — a weekly status update**
- Task: Summarize this week's progress for my manager.
- Context: Finished the budget review, still waiting on vendor pricing, one blocker with IT access.
- Format: Three bullet points, professional tone, under 100 words.
- Evaluate: Does it lead with the blocker, since that's what needs action?
- Iterate: Ask it to move the blocker to the top if it buried it.

**Example 2 — meeting notes into action items**
- Task: Turn these rough meeting notes into a clean action-item list.
- Context: [paste your actual rough notes]
- Format: A table with columns for Owner, Action, and Due Date.
- Evaluate: Did it correctly assign owners, or did it guess wrong on any?
- Iterate: Correct any misattributed owners and ask it to regenerate just that row.

## When you're done

Read your own prompt back once, out loud if you can. If a colleague reading it cold wouldn't know what you wanted, the AI won't either — that's usually a Context or Format gap, not a Task problem.
